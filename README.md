# AI Real Estate Market Intelligence Platform

## Business Problem
Real estate decisions rely on pricing, location, property size, and market context. This project uses real-world listing data to create a market intelligence workflow for pricing strategy and investment research.

## Dataset
USA real estate listing data.  
The cleaned sample contains 27,000+ property records.

## Key Outputs
- Cleaned property listing dataset
- City-level market scorecard
- Median price and price-per-square-foot analysis
- Market opportunity scoring
- AI-style market summary framework
- Excel market workbook
- Dashboard blueprint

## Business Value
This project shows how analytics can help agents, investors, and analysts compare markets, evaluate pricing, and identify opportunity areas.

## Tools
Python, Pandas, SQL, Excel, Streamlit, Power BI/Tableau planning

## How to Run
```bash
pip install -r ../../requirements.txt
cd src
python market_scoring.py
python ai_market_summary.py
streamlit run app_streamlit.py
```
